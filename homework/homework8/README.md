# ДЗ 8: человек и гуманоид

Согласованная постановка:

- Класс 1: обычные люди. Класс 0: двуногие человекоподобные роботы и костюмы роботов, в том числе надетые человеком.
- Только фотографии. Грим, иллюстрации, схемы и рендеры исключаются при визуальном отборе.
- Базовая классификация: 100 фотографий каждого класса; kNN, SVM, Logistic Regression.
- Оба класса можно кадрировать вокруг объекта. Для детекции людей используются целые сцены.
- Дополнительный тест детектора: 50 новых фотографий с людьми и 50 с гуманоидами.
- Разрешено использовать исходную разметку Penn–Fudan с визуальной проверкой.

## Запуск

Рекомендуется Python 3.12. Установить зависимости:

```powershell
python -m pip install -r requirements.txt
```

Затем выполнить ячейки ноутбука сверху вниз. Модели и HOG реализованы в `hog_lab.py`.

## Источники и разметка

Люди: https://www.cis.upenn.edu/~jshi/ped_html/ (Penn–Fudan).
Гуманоиды: реальные изображения камер B-Human: https://b-human.informatik.uni-bremen.de/public/datasets/robots/ . Используются два обучающих архива апрельского матча и отдельный июльский матч для теста. Основные роботы — NAO; в независимом тесте есть также другие двуногие роботы гуманоидной лиги. Расширение на пришельцев и костюмы эта выборка не подтверждает. Wikimedia первоначально рассматривалась, но ограничила загрузку; её кандидаты не включаются в эксперименты.

`people_manifest.json` хранит разделение фотографий, рамки, пути к целым сценам и кадрам объектов. Для Penn–Fudan рамки вычисляются по исходным экземплярным маскам; мелкие люди на фоне могут не иметь разметки источника.

`robots_manifest.json` хранит кадры, источник архива, имя исходной фотографии и исходную рамку стоящего робота. Для кадрирования к рамке B-Human добавлен небольшой боковой запас, потому что исходная разметка не включает руки. Все 150 выделенных областей просмотрены визуально; рисунков, рендеров и людей в гриме в них нет.

## Результаты выполнения

`hog_features.csv` содержит таблицу «изображение — полный HOG-вектор — класс». Числовая копия и индексы train/test — в `hog_features.npz`. Разбиение также записано в `classification_split.json`.

Предсказания рамок, их баллы и результаты сопоставления всех 100 тестовых изображений сохраняются в `detector_results.json`. Эти файлы пересоздаются при выполнении ноутбука. Визуальные результаты и интерпретации находятся непосредственно в ноутбуке.

Получено: kNN 85% → 92.5% после аугментации, SVM и Logistic Regression — 100% на 40 кадрированных тестовых изображениях. Детектор: Accuracy наличия 72%, средний лучший IoU 0.600, Precision рамок 9.3% при Recall 84.3%. Низкая Precision и 1040 лишних рамок показывают, что детектор пока ненадёжен.

Результат классификации оценивает небольшой выбранный набор, а не универсальную способность отличать любого человека от любого гуманоида. Источники различаются по фону, разрешению, смазыванию движения и освещению; это потенциальные побочные признаки класса. Отсутствие точных дубликатов не гарантирует отсутствия близких кадров одного видеоматча.
